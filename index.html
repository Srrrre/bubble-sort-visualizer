理解算法

每一轮，都少看一个数。

  1. 比较邻居从下标 0 出发，比较 a[j] 与 a[j + 1]。左边更大就交换，否则保持原位。
  2. 确定一个位置一轮结束，未排序部分的最大值到达最右侧。下一轮不再访问已就位的元素。
  3. 及时停止如果整轮都没有交换，说明剩余部分也已有序，可以提前结束。
平均 / 最坏时间 O(n²)最好时间 O(n)算法额外空间 O(1)

只在左边严格大于右边时交换，因此相等元素的相对顺序不变：这是稳定排序。

C++ 参考实现与画布中的步骤对应
// a 是数组，n 是元素个数
void bubbleSort(int a[], int n) {
    for (int end = n - 1; end > 0; --end) {
        bool swapped = false;
        for (int j = 0; j < end; ++j) {
            if (a[j] > a[j + 1]) {
                int temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
                swapped = true;
            }
        }
        // 本轮没有交换，提前结束
        if (!swapped) break;
    }
}

TreeNode、visit 与空指针约定
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};
void visit(TreeNode* root) {
    std::cout << root->val << ' ';
}

代码为教学函数片段。完整程序还需 <iostream>；层序遍历需 <queue> 和 using std::queue。T1、T2 是节点唯一编号，不是真实内存地址。空孩子不会计为树节点，但也会触发一次递归调用和终止判断。

“已访问”表示已经输出数值；“已完成”表示该节点的函数即将返回（层序遍历中表示孩子已处理完）。返回后，父帧高亮刚完成的调用语句；再点下一步才继续后续语句。
