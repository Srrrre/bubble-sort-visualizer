理解算法

每一轮，都少看一个数。

  1. 比较邻居从下标 0 出发，比较 a[j] 与 a[j + 1]。左边更大就交换，否则保持原位。
  2. 确定一个位置一轮结束，未排序部分的最大值到达最右侧。下一轮不再访问已就位的元素。
  3. 及时停止如果整轮都没有交换，说明剩余部分也已有序，可以提前结束。
平均 / 最坏时间 O(n²)最好时间 O(n)算法额外空间 O(1)

只在左边严格大于右边时交换，因此相等元素的相对顺序不变：这是稳定排序。

C++ 参考实现与画布中的步骤对应
// a 是数组，n 是元素个数
void bubbleSort(int a[], int n) {
    for (int end = n - 1; end > 0; --end) {
        bool swapped = false;
        for (int j = 0; j < end; ++j) {
            if (a[j] > a[j + 1]) {
                int temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
                swapped = true;
            }
        }
        // 本轮没有交换，提前结束
        if (!swapped) break;
    }
}
